# 💳 Credit Card Fraud Detection using Machine Learning

## 📌 Project Overview

This project is a Machine Learning-based web application that detects whether a credit card transaction is legitimate or fraudulent.

The model is trained using the Credit Card Fraud Detection dataset and deployed using Streamlit.

---

## 🚀 Features

- Detects fraudulent credit card transactions
- Random Forest Classifier
- SMOTE for handling class imbalance
- Interactive Streamlit Web Application
- Probability-based prediction
- Feature Importance Analysis

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Joblib
- Matplotlib

---

## 📊 Machine Learning Workflow

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Train-Test Split
- Random Forest Model
- SMOTE Oversampling
- Model Evaluation
- Feature Importance
- Model Deployment

---

## 📈 Model Performance

### Random Forest + SMOTE

- Accuracy: **99.95%**
- Fraud Detection Recall: **0.77**
- Fraud Detection Precision: **0.91**
- F1 Score: **0.83**
